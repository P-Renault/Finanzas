CCF · GALERÍA DE MÓDULOS RESPONSIVE 3.5

Este paquete contiene exclusivamente archivos modificados y nuevos para actualizar la sección “Módulos principales” de la landing page.

Cambios:
- Se integran seis capturas reales del sistema: Resumen, Presupuesto, Deudas, Movimientos, Calendario y Planificación.
- Las capturas se recortaron únicamente para retirar la barra de estado, la interfaz del navegador y los controles Android. Se conserva completa la vista útil del sistema, incluida su navegación interna.
- Escritorio: seis tarjetas en una fila de seis columnas.
- Móvil: una columna con las seis tarjetas apiladas, una por fila.
- Cada tarjeta incorpora una descripción y un control “Ver detalle” desplegable.
- Se actualiza el parámetro de versión del script para evitar que el navegador reutilice la versión anterior en caché.

- B230-PORTAL-ACCESO-FINAL-PREMIUM-1.1.js

Nota: se solicitaron seis módulos y se entregan seis filas en móvil. No se inventa un séptimo módulo ni se duplica una captura.

Instalación:
Extraer el ZIP en la raíz del proyecto, conservando las rutas relativas y sobrescribiendo únicamente los archivos incluidos.
